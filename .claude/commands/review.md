# Claude 명령어: Review

백엔드 코드를 리뷰합니다. 코드는 수정하지 않고 결과만 보고합니다.

## 리뷰 대상

- 인자: $ARGUMENTS
- 인자가 없으면 `git diff HEAD`와 추적되지 않은 파일을 대상으로 합니다.
- 변경 사항도 없으면 범위를 지정해 달라고 요청하고 멈춥니다.

## 프로세스

1. `CLAUDE.md`에서 이 프로젝트의 구조와 규칙을 확인합니다.
2. 변경된 코드와 호출하는 쪽, 호출되는 쪽을 함께 읽습니다.
3. 아래 항목을 점검합니다. 스타일보다 실제 동작 오류를 우선합니다.
4. 지적하기 전에 실제로 발생하는 상황인지 코드로 확인합니다.

## 점검 항목

- **동작:** 로직 오류, 경계값, null 처리, 동시성
- **구조:** Controller → Service → Repository 계층 분리, 의존성 주입, 계층을 넘는 호출
- **데이터:** DTO 사용, 엔티티 노출, 트랜잭션 범위, 원자성이 필요한 작업
- **오류 처리:** 예외 누락, 삼켜지는 오류, 실패 시 데이터 상태
- **API:** 응답 형식 일관성, 상태 코드, 입력 검증, 하위 호환성
- **성능:** N+1 쿼리, 페이지네이션 없는 조회, 불필요한 반복 호출
- **테스트:** 변경된 동작을 검증하는 테스트가 있는지

보안 취약점을 집중 점검하려면 `/security-check`를 사용합니다.

## 출력 형식

심각한 순서로 정리합니다. 문제가 없으면 없다고 짧게 말합니다.

```text
[심각도: 높음/중간/낮음] 파일:줄
- 문제: 어떤 입력이나 상태에서 어떤 결과가 나는지
- 제안: 구체적인 수정 방법
```

마지막에 확인한 범위와 확인하지 못한 항목을 적습니다.
